GoalCheck

Privacy Policy

Applies to GoalCheck, GoalCheck Advance (web + Android) · Last updated: 2026-10-19

The short version: we collect nothing. Your data never leaves your device.

What we collect

Nothing. GoalCheck has no account system, no sign-up, no analytics, no telemetry, no crash reporting, no advertising, no remote config and no tracking of any kind. The app makes zero network calls for its core functionality.

Where your data lives

All goals, tasks, habits, settings and statistics are stored only on your own device:

  • Web app: in your browser's localStorage. It never reaches any server — there is no server to reach.
  • Android app: in the app's private WebView storage. It cannot be read by other apps.

You can export a full JSON backup at any time (Settings → Export) and re-import it anywhere. Deleting your browser data or uninstalling the app deletes everything permanently.

Network access

The web app performs no background requests beyond loading its own static files. The Android app is built with the android.permission.INTERNET permission deliberately removed — verified automatically on every release build — so the operating system makes "no network access" technically true, not just a policy statement.

Android permissions

  • POST_NOTIFICATIONS / RECEIVE_BOOT_COMPLETED — optional, local-only reminders (e.g. a finished Pomodoro while the app is in the background). No data leaves the device.
  • No location, no camera, no microphone, no contacts, no storage, no phone, no network.

Third parties

None. No analytics SDKs, no ad networks, no font CDNs, no embedded services. This page itself is a static file served by GitHub Pages; GitHub's own infrastructure logging may apply when you load it — see GitHub's privacy statement for that.

Backups you create

JSON/theme exports are generated locally and saved wherever you choose. If you store them with a third-party sync provider (e.g. Syncthing/WebDAV via the sync-file feature), that provider's terms apply to those files — the app itself still touches nothing networked.

Changes

Any change to this policy will be published at this URL and noted in the repository's changelog. Given the architecture, meaningful privacy regressions would be visible in the open-source code.
