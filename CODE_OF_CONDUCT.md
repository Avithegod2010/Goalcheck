# Code of Conduct

## Our promise
GoalCheck is a local-first, FOSS project built on respect. Everyone contributing —
via issues, PRs, discussions or translations — agrees to keep this space welcoming,
harassment-free and on-topic.

## Expected behavior
- Be kind, patient and assume good intent.
- Give and receive constructive criticism gracefully.
- Focus on the code and the user experience; respect differing skill levels.
- Respect the project's core promise: privacy, local-first data, zero network.

## Unacceptable behavior
- Harassment, discrimination, or personal attacks of any kind.
- Trolling, insults, or deliberate derailing.
- Publishing others' private information without consent.
- Advocating for the removal of the privacy guarantees (offline-only, no tracking)
  without an exceptionally good, transparent technical argument.

## Enforcement
Maintainers may edit or remove comments, issues and PRs, and may temporarily or
permanently ban contributors who violate this pledge. Report problems via a GitHub
issue tagging the maintainer, or through GitHub's private contact for the repository.

This pledge is adapted in spirit from the Contributor Covenant (CC BY 4.0).
